## 📌 Featured Projects

### 🔹 Production-Grade 3-Tier Architecture on AWS
> Fault-tolerant infrastructure spanning 2 Availability Zones with isolated tiers for web, app, and database.

- Configured **ALB** with path-based routing + **ASG** with dynamic scaling (2→4 instances)
- Deployed **RDS MySQL Multi-AZ** in private subnets — zero single point of failure
- **CloudWatch + SNS** alarms enabling sub-5-minute issue detection

### 🔹 AWS Infrastructure Automation — Terraform + GitHub Actions
> Full IaC pipeline automating 10+ AWS resources with ~60% less manual setup time.

- Built **4+ reusable Terraform modules** for consistent dev/prod deployments
- **S3 + DynamoDB** remote backend with state locking
- **GitHub Actions** automates `fmt`, `validate`, `plan` on PRs and `apply` on merge

### 🔹 AWS Cost Optimization Toolkit
> Serverless automation (Python/Boto3) that hunts down waste before it hits the bill.

- Detects stale resources — unattached EBS volumes, unused EIPs, oversized S3 buckets
- **Lambda + EventBridge** scheduled EC2 shutdown/startup for off-hours savings
- Real-time **SNS** cost alerts for proactive cleanup

### 🔹 Serverless Image Processing Pipeline
> Event-driven pipeline that reacts to S3 uploads with zero standing compute.

- **Lambda**-triggered processing on S3 upload events via Python/Boto3
- **SNS** notifications + **CloudWatch** alarms for full observability
